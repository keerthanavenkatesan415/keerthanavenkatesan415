## ⭐ Featured Project: NAVIS — Vision–Language Dataset Navigator  
🚗 **Break Through Tech AI Studio | Partner: Latitude AI (Ford)**  

NAVIS is a **multimodal semantic search system** designed to help autonomous-vehicle engineers rapidly explore massive driving datasets.

**🔍 What It Does**
- Enables **natural-language search** over autonomous-driving image datasets  
- Retrieves semantically similar frames using **CLIP embeddings + FAISS (HNSW)**  
- Generates **automatic scene summaries** with BLIP captioning  
- Reduces dataset exploration time from **hours to seconds**

**🛠 How It Works**
- Processes **~25,000 frames** across BDD100K, KITTI, and Argoverse  
- Backend: **Python, FastAPI, FAISS, PostgreSQL (Supabase)**  
- Frontend: **Next.js** interactive search interface  
- Fully containerized using **Docker**

**🚀 Highlights**
- Industry-sponsored project with real business relevance  
- Scalable, modular architecture for adding new datasets  
- Demonstrates multimodal ML, large-scale data processing, and system design
